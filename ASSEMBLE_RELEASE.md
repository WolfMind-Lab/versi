# VERSI — come ottenere la release completa

La cartella `public/` NON viene sostituita in questa patch: il frontend ufficiale e completo del repository `WolfMind-Lab/versi` è già quello attuale su `main`.

Questa patch contiene il backend PostgreSQL/Neon, `package.json`, `render.yaml` e la documentazione. Per una release completa, copia questi file nel repository mantenendo intatto `public/`.

Il frontend ufficiale verificato sul repository attuale è identico alla versione completa del commit `8f3a125` per `public/app.js`, `public/style.css` e `public/index.html`.
